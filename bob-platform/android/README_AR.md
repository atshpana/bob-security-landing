# تطبيق BOB Android الأصلي — مرحلة البناء الأولى
هذا **مشروع Android أصلي بكوتلن**، وليس تحويلًا لصفحة ويب إلى APK. يعرض 14 شاشة M-10 إلى M-23 مع حالات UNKNOWN/NOT_CONNECTED/UNSUPPORTED الآمنة، ويمنع ادعاء تنفيذ وظائف حماية غير متاحة.

**غير مكتمل:** M-01 إلى M-09، عقود المصادقة، حماية محلية حقيقية، تكامل Play Integrity، AMAPI، الدفعات، صلاحيات الهاتف المتقدمة، الخلفية، جميع التدفقات الفرعية، اختبارات الأجهزة. لا يُعد هذا تطبيق BOB المكتمل.

**بناء APK:** GitHub Actions > BOB Android preview APK > Run workflow (أو بعد دفع التغييرات)، ثم تنزيل Artifact المسمى BOB-Android-preview-debug-APK إذا نجح البناء. ملف Debug مخصص لاختبار واجهة محلية، لا للتوزيع أو النشر. لا يوجد APK مثبت النجاح حتى يظهر نجاح الـworkflow.
**قاعدة البيانات:** غير متصلة طبقًا لقرار صاحب المشروع.
