# BOB 4.0 §11 — تنفيذ قواعد الموزعين قبل قاعدة البيانات
تمت إضافة وحدة قواعد أعمال قابلة للاختبار، بدون ربط قاعدة بيانات أو أموال فعلية، تشمل: إنشاء الموزع الإداري دون نسبة افتراضية؛ سياسة النسبة المئوية المعتمدة والمؤرخة؛ فرع واحد وحصته المستقطعة من الأصل؛ التحقق من أهلية الصرف المباشر؛ أول إحالة موثقة ونافذة التقاط 30 يومًا؛ نافذة أول تحصيل مؤهل 168 ساعة واستثناء سلسلة التجربة الرسمية؛ عدم احتساب QR أو التثبيت كعمولة؛ حالات العمولة ودليل التحصيل والصرف؛ التقريب لأعلى إلى أصغر وحدة نقدية وفارق التقريب؛ تصحيح الإسناد بموافقتين مستقلتين.
## غير منفذ بعد
لوحة الموزع الفعلية، مولد QR، سجل الأحداث، الربط الرسمي بإحالات Google Play والتحصيل والفواتير، تخزين snapshots غير قابلة لإعادة الكتابة، استردادات جزئية وقيود العكس، التسوية والدفع، مراقبة الاحتيال، واجهات التشغيل والدعم؛ هذه أجزاء لازمة قبل اعتبار المنظومة مكتملة.
## شروط الأمان
لا تقبل هوية موزع أو عمولة من التطبيق كحقيقة مالية. لا تعتمد الدفع دون تحقق المصدر الرسمي، ولا تخلط حسابات الأسرة والمؤسسة والموزعين.
