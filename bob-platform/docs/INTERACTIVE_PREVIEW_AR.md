# BOB — رابط المعاينة التفاعلية (Static Preview)

**رابط المعاينة:** `https://raw.githack.com/atshpana/bob-security-landing/feature/bob-platform-pre-db-20261115/bob-platform/public/preview.html`

**ما يُعرض؟** نسخة RTL عربية ببيانات وهمية يمكن التجول فيها والتبديل بين الأدوار، وإنشاء حوادث وتذاكر ومسودات ومشاهدة سجل الشاشات.

**طريقة العمل:** `preview.html` يحمّل `mock-api.js` قبل `app.js`، حيث يتعامل مع جميع استدعاءات `/api/` داخل المتصفح دون استدعاء الخادم. ملفات JS/CSS والشعار والسجل يُحمّلها من GitHub عبر خدمة معاينة الملفات الثابتة. لا توجد قاعدة بيانات ولا أي جهاز متصل.

**تنبيه:** `raw.githack.com` خدمة خارجية للمعاينة وليست استضافة إنتاجية، وقد تطلب تأكيدًا أول مرة. لا تكتب بيانات حقيقية في أي نموذج؛ جميع النتائج محاكاة وتُمحى عند إعادة تحميل الصفحة. لا توزع رابط المعاينة على أنه المنتج النهائي أو ضمان لتشغيل أوامر Android.

**في التشغيل المحلي:** `index.html` ما زال يستخدم خادم Node وواجهات API، أما `preview.html` فيستخدم المحاكاة بالكامل.

**الهوية:** `bob-logo.jpeg` يشير إلى نفس Git blob المعتمد دون تغيير محتوى الصورة.
