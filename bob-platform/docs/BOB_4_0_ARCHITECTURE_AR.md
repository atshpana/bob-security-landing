# BOB 4.0 — تصحيح البنية وفق المرجع

المرجع الحاكم: **BOB_4_0_OWNER_APPROVED_FROZEN.docx**، §§0.8، 2.4، 3، 4، 9، 10، 15، 16، 21–23، 29.

## منتج واحد لا عدة منتجات
**نفس الحساب والمنظومة** في ثلاث تحديثات تراكمية: Production Base → BOB Public → Guard Personal → Guard Managed. الباقة العائلية تكوين عضوية وفوترة في Personal فقط، ولا تمنح مراقبة بالغين أو أوامرهم. الإدارة المؤسسية مستقلة ضمن نفس المنتج مع سياق المؤسسة والجهاز وAMAPI.

## التقنيات المعتمدة
- `mobile/`: **Flutter** للواجهات العربية؛ و**Kotlin** لمكوّنات Android الرسمية المسموح بها فقط. minSdk=30؛ Target API يتحقق منه قبل الإصدار.
- `web/`: **React** لموقع W-01..W-08 ولوحات العملاء/المؤسسة والإدارة والشركاء والدعم.
- `backend/`: **FastAPI** لعقود الخادم؛ يفشل مغلقًا بدون `BOB_DEMO_ONLY=1`؛ جميع الأفعال الظاهرة محاكاة فقط.
- `schema/mysql-draft.sql`: مخطط **MySQL** غير منفذ؛ **Redis** مخصص للحالات المؤقتة عند التكامل لاحقًا، دون اعتبار مصدر حقيقة للأوامر.
- `data/`: **104** Screen IDs أصلية، **35** Subflow IDs، **40** Capability IDs مع حالة الإنتاج المغلقة.

## قرار معماري مهم
النموذج القديم `src/server.mjs` و`public/preview.html` موجودان كتجربة سابقة فقط وليس backend أو واجهة الإنتاج المعتمدة. مخطط PostgreSQL القديم **حُذف** من سجل البناء النشط. لا يوجد ربط DB أو خادم أجهزة أو دفع أو حارس AI أو تقارير رسمية.

## شروط تسبق الإنتاج
- `M-02` المصادقة الحقيقية، هوية الجهاز، MFA، جلسات آمنة، وحقوق حذف الحساب؛ استحقاق شراء مدفوع لا يتحقق من حالة `Purchase PENDING`.
- `Capability Preflight` حديث من الخادم ثم `Execution Recheck` محلي على الهاتف قبل أي أثر حساس. الطلب/الوصول/القبول **ليس نجاحًا**؛ يحفظ `RESULT_UNCONFIRMED` حتى دليل متحقق.
- `F-036` خمس عقود حسية مستقلة، لا يتم تشغيل حساسات في الخلفية بطريق التفاف على Android.
- `Guard Managed` لا يفتح إلا بعد `EXT-AMAPI-001/002` + عقد المؤسسة + حصة وقدرة الجهاز + إعادة فحص تنفيذ.
- `CFG-AGE-002` غير مهيأ؛ **دعوات الأسرة محظورة** حتى اعتماد قاعدة العمر للسوق.
- المؤسسة لا ترى خارج tenant، موظف الدعم لا يرى قياسات الجهاز، والباقة العائلية لا ترى أجهزة بالغ آخر.
- بيانات الأدلة الأصلية لا يتم تعديلها، وإصدار التقرير الرسمي منفصل عن المعاينة والتصدير/إعادة الإصدار.
- حذف حساب BOB لا يساوي مسح الهاتف، وUnbind/Replacement/Unenrollment/Wipe/Delete إجراءات منفصلة.
- مسار Android `CH-SMS-IN` المؤسسي لا يُضمّن في نسخة Public/Personal؛ يظل خارج البناء حتى بوابة `EXT-PLAY-004`.

## ما الذي لا يعنيه نجاح اختبارات الكود؟
نجاح اختبار React/FastAPI/Flutter الشكلي لا يثبت اختبار هاتف حقيقي، قبول المنصة، تأهيل AMAPI، دفع Google Play، الأمان الإنتاجي، أو إغلاق بوابات الوثيقة.
