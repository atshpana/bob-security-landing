# BOB Security 4.0 — المعمارية المعتمدة (الفرع المعزول)

**المرجع الوحيد الحاكم:** `BOB_4_0_OWNER_APPROVED_FROZEN.docx` — OWNER APPROVED / FROZEN / DERIVATION ALLOWED / PRODUCTION GATED.

**الفرع:** `feature/bob-platform-pre-db-20261115`، منفصل عن `main`.

## ما هو BOB؟
منظومة أمن واسترداد لأجهزة Android، منتج واحد يتدرج تراكمياً من قاعدة إنتاج مشتركة `Foundation` إلى `BOB Public` ثم `Guard Personal` ثم `Guard Managed`. تشمل موقع الويب، تطبيق الهاتف، لوحات الأجهزة والحسابات والأدلة والإدارة والمؤسسات والشركاء والدعم. يشمل نطاق المنتج **104 شاشات أم، 35 Subflow، 40 قدرة ذات مسار بناء**، لا تمثل حالة اكتمال أو إطلاق.

## المسارات الموجودة الآن

| المسار | التقنية المعتمدة | محتواه في هذا الفرع |
|---|---|---|
| `web/` | React / Vite | موقع W-01 ولوحات تجريبية متجاوبة لبعض مسارات D/A/E/AD/EN/P/S ومعاينة عقدية لبقية الشاشات؛ شعار BOB الرسمي |
| `mobile/` | Flutter + Kotlin | تطبيق أندرويد أصلي من جهة UI وMethodChannel محدود، عروض M10 وM13 وM21 وM22 وM23 مع باقي العقود؛ لا أوامر هاتف فعلية |
| `backend/` | Python FastAPI | عقود API تجريبية وعزل أدوار وفحوص أهلية وقناة أوامر محاكاة، دون ربط MySQL |
| `schema/mysql-draft.sql` | MySQL | هيكل مقترح غير منفذ؛ Redis غير متصل |
| `data/` | JSON source contracts | السجلات الحاكمة 104/35/40 ونموذج الطبقات والبوابات |
| `docs/` | حوكمة وتقرير | الفروق عن النسخة السابقة وحدود الاكتمال |

الكود الأقدم `src/server.mjs` و`public/preview.html` **نموذج قديم للمعاينة فقط**، ليس جزءاً من Stack الإنتاج. **أزيل المخطط القديم PostgreSQL** من فرع البناء، لأن المرجع يوجب MySQL + Redis.

## كيف أشغّل المشاريع؟
- React: داخل `web/`: `npm install` ثم `npm run dev`. البناء `npm run build`.
- FastAPI: داخل `backend/`: `pip install -r requirements.txt` ثم `BOB_DEMO_ONLY=1 uvicorn app.main:app --host 127.0.0.1 --port 8000`.
- Flutter: اتبع `mobile/README.md` لتوليد ملفات Android المطلوبة ثم `flutter pub get` و`flutter run`.
- GitHub Actions: `.github/workflows/bob-stack.yml` لاختبارات Python/React/Flutter، وعرض نتائج البناء أو Artifact تجريبي بعد نجاح التشغيل.

## ممنوعات حتى ربط البيانات والبوابات
لا تنشر FastAPI التجريبي على الشبكة: دور `x-demo-role` محاكاة وليس مصادقة. لا تستقبل بيانات شخصية من المستخدم. **CFG-AGE-002** غير مهيأة، لذلك دعوات الأسرة الحقيقية مغلقة. **EXT-AMAPI-001/002** غير مثبتة، فالأوامر المؤسسية/المسح/Lost Mode مغلقة. لا يتم تشغيل أي حساسات أو تنفيذ أوامر فعلية أو دفع أو إصدار تقارير رسمية أو حارس AI.

إكمال 104 شاشة وعقودها و40 قدرة واختبارات أجهزة Android غير حاصل في هذه النسخة، حتى لو اجتازت اختبارات بناء الكود. يتطلب كل عنصر عقد G0 واختبارات قبول ومواءمة البوابات قبل الادعاء بجاهزية الإنتاج.

## شرط المستخدم
