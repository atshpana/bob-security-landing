# BOB Security — فرع بناء معزول قبل ربط قاعدة البيانات

**الفرع:** `feature/bob-platform-pre-db-20261115`

هذا تنفيذ **أولي تفاعلي** مبني على `BOB 4.0 — OWNER APPROVED FROZEN`، ولا يبدل المرجع أو يُعلن جاهزية الإنتاج.

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. ادخل مجلد `bob-platform`.
3. نفّذ `npm start`.
4. افتح `http://127.0.0.1:4173`.
5. للاختبارات نفّذ `npm test`.

**تحذير:** الخادم يعمل على `127.0.0.1` فقط، ولا يحتوي على نظام مصادقة إنتاجي. ممنوع نشره بصورة عامة كما هو. تغيير الدور داخل الواجهة **محاكاة فقط** وليس تفويضًا حقيقيًا.

## المنفذ الآن
- واجهة عربية RTL متجاوبة للموبايل والكمبيوتر، مع فصل مساحات المالك والأسرة والمؤسسة وإدارة BOB والشريك والدعم.
- بيانات تجريبية في ذاكرة الخادم، دون قاعدة بيانات أو ملفات إنتاجية.
- سجل أسماء **104 شاشات أم** و**35 تدفقًا فرعيًا** من مرجع BOB 4.0، مع وسم واضح لما هو نموذج تفاعلي جزئي وما لا يزال عقدًا فقط.
- محاكاة فحص قدرة الجهاز وحداثتها، وقائمة أوامر محدودة، ورفض صريح للصلاحيات غير المتاحة.
- إنشاء حادث تجريبي، ومعاينة تقرير **غير موقع وغير صادر**، وتذكرة دعم تجريبية.
- عضوية الأسرة والدعوات المسودة فقط، دون عرض موقع أو حالة جهاز عضو بالغ.
- مؤسسات: أجهزة تجريبية ومسودات سياسات غير مطبقة؛ AMAPI مغلق.
- إدارة: عرض حسابات نموذجية، مسودات محتوى، سجل تدقيق تجريبي.
- اختبار وحدات + اختبارات HTTP + GitHub Actions؛ تحقق من النتائج في صفحة Actions.

## غير مكتمل / ممنوع اعتباره جاهزًا
- **ربط قاعدة البيانات** وإعداد الهجرة RLS والعزل بين المؤسسات والنسخ الاحتياطي؛ `schema/postgres.sql` مسودة غير مطبقة.
- المصادقة الحقيقية MFA والأدوار من قاعدة بيانات الخادم، وحماية الجلسات وطلبات الحقوق.
- تطبيق Android أصلي وإثبات الأجهزة والصلاحيات وExecution Recheck، والبوابات الخارجية Android Enterprise / AMAPI.
- التسعير والتحقق من الشراء والفوترة والدفع والإيداع الفعلي، ودورة العمولة.
- تشغيل كاميرا/ميكروفون/موقع/أوامر جهاز حقيقي، إخطار جهة طوارئ، استقبال FCM، أو التحكم عن بُعد.
- إصدار/توقيع PDF فني رسمي وحفظ الأدلة والتجزئة وسلسلة الحيازة.
- تنفيذ كل شاشة من الـ104 وكل Subflow من الـ35 و40 قدرة وفق عقود قبولها؛ المنفذ الآن **معاينات وظيفية لجزء منها**.
- اختبارات الأجهزة، الأمن، سهولة الوصول، الاختراق، والتحقق التشغيلي `RUNTIME_QUALIFICATION`.

## قاعدة العمل
المرجع الأصلي **مجمّد**، والتطوير في فرع منفصل داخل `bob-platform/`، دون تعديل ملفات الموقع المنشور على `main`. لا تُرفع مفاتيح أو بيانات مستخدمين حقيقية إلى المستودع. هذا المستودع **عام**؛ لا تضع فيه الوثائق الخاصة أو أسرار المشروع.

## مرجع التنفيذ
- BOB 4.0 §§4, 7, 9, 10, 16, 21.22–21.30, 21.44.1, 22, 29.3
- ربط الأنظمة الخارجية يخضع للبوابات والتراخيص المعتمدة ولا يُفتح بافتراض القدرة.
